# หน้าค้นหาและจองห้องสำหรับนักศึกษา

ปรับด้วย impeccable โดยคงธีมสีดินแดงของมหาวิทยาลัยขอนแก่นและเงื่อนไขการจองเดิม ผู้ใช้เริ่มด้วยวันที่ เวลาเริ่ม เวลาสิ้นสุด และจำนวนคน ตามลำดับที่ผู้ใช้เลือกในบทสนทนา

## สิ่งที่ปรับ

- ลดส่วนแนะนำขนาดใหญ่และสถิติ ให้แบบค้นหาและผลห้องว่างขึ้นมาก่อน
- คำนวณผลทันที เรียงห้องที่มีความจุเหมาะสมก่อน แสดงเฉพาะห้องว่างเป็นค่าเริ่มต้น มีตัวเลือกดูห้องที่ไม่ว่างพร้อมเหตุผล
- ปุ่มวันนี้/พรุ่งนี้ช่วยเลือกวันเร็ว ตัวกรองอาคาร ประเภท อุปกรณ์ และชื่อห้องอยู่ในส่วนเพิ่มเติม มีปุ่มล้างและทางออกเมื่อไม่พบห้อง
- ตรวจช่วงเวลาที่ผ่านไปแล้ว ระยะการจองล่วงหน้า ระยะเวลาใช้งาน และจำนวนคนก่อนแสดงผล
- ส่งจำนวนคนจากการค้นหาไปยังฟอร์มจอง แสดงความจุสูงสุดแยกจากจำนวนผู้เข้าร่วม
- ฟอร์มหลักเหลือวัตถุประสงค์และจำนวนคน มีข้อความตัวอย่างให้เลือก ส่วนอุปกรณ์ยืมเพิ่มและรายชื่อผู้เข้าร่วมเปิดเมื่อจำเป็น
- หลังส่งสำเร็จ แสดงรหัสคำขอและสถานะรออนุมัติ พร้อมทางไปการจองของฉัน
- การจองของฉันใช้รายการที่อ่านง่ายบนมือถือ แสดงสถานะ วันเวลา จำนวนคน และขั้นตอนถัดไป ปุ่มเช็คอินและยกเลิกแสดงเมื่อเข้าเงื่อนไข
- ย้ายเครื่องมือสลับบทบาท เวลา และเริ่มข้อมูลใหม่ไปส่วนตั้งค่าต้นแบบท้ายหน้า

## การตรวจ

ตรวจ TypeScript และสร้างเว็บสำเร็จ การทดสอบเงื่อนไขธุรกิจเดิมผ่าน 8 รายการ ตรวจด้วยเบราว์เซอร์ที่ขนาด 1440×1000, 390×844 และ 320×844 ครอบคลุม:

- เปลี่ยนวัน เวลา และจำนวนคนแล้วผลเปลี่ยน ช่วงเวลาไม่ถูกต้องมีข้อความช่วยแก้
- กรองจนไม่พบห้องและล้างกลับมาได้ ห้องที่ไม่ว่างแสดงเหตุผลและปุ่มจองไม่ทำงาน
- เลือกห้องแล้วจำนวนคนส่งต่อ เลือกวัตถุประสงค์ ยืมอุปกรณ์เพิ่ม และส่งคำขอจำลองสำเร็จ
- รายการใหม่แสดงสถานะรออนุมัติและอุปกรณ์ ยกเลิกรายการทดสอบได้โดยคงรายการเดิม
- เครื่องมือทดลองบทบาทและหน้าเจ้าหน้าที่ยังเข้าถึงได้
- หน้าค้นหาและรายการจองไม่ล้นความกว้างบนมือถือ

ตัวตรวจรูปแบบของ impeccable ไม่พบรายการแจ้งเตือนในไฟล์ที่ปรับ การตรวจนี้เป็นการทดสอบต้นแบบโดยผู้พัฒนา ยังไม่ได้ทดสอบกับกลุ่มนักศึกษาจริง

## ขอบเขต

ยังใช้ข้อมูลจำลองและเวลาในต้นแบบ การแจ้งเตือนและการอนุมัติไม่มีการส่งออกสู่ระบบจริง คงคำขอทดสอบที่ยกเลิกไว้ในประวัติเพื่อไม่รีเซ็ตข้อมูลเดิม ไม่มีการแก้ SYSTEM_ARCHITECTURE, DATABASE_REVIEW, ข้อเสนอ หรือ SQL/DDL ต้นฉบับ
