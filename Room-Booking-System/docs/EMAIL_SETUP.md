# ตั้งค่าอีเมลด้วย Resend

อัปเดต 12 ต.ค. 2569: ตั้งค่า Production บน Vercel แล้วสำหรับ SMTP_HOST=smtp.resend.com, SMTP_PORT=465, SMTP_SECURE=1 และ SMTP_USER=resend ยังไม่ตั้ง SMTP_PASSWORD/MAIL_FROM เพราะการติดตั้ง Resend ถูกหยุดที่ `integration_terms_acceptance_required` ซึ่งบริการกำหนดให้เจ้าของบัญชียอมรับผ่านเบราว์เซอร์ และทีม Vercel ยังไม่มีโดเมนผู้ส่ง ไม่มีการสร้างบัญชีสำเร็จหรือส่งอีเมลจริงในรอบนี้

หน้าเจ้าของบัญชียอมรับเงื่อนไข: https://vercel.com/markstricks-projects/~/integrations/accept-terms/resend?source=cli

เมื่อยอมรับแล้วและมีโดเมนที่เป็นเจ้าของ ให้ติดตั้ง resource เดียวชื่อ `kku-space-email` ด้วย plan `free` ใน project เดิม เลือกโดเมนและ region จาก metadata ที่ CLI รองรับ และตรวจ installation/resource ก่อนติดตั้งซ้ำ ห้ามซื้อโดเมนหรือเลือกแผนเสียเงินโดยไม่ได้รับคำสั่งที่ระบุค่าใช้จ่าย

เลือกใช้ Resend ผ่าน SMTP ที่ระบบรองรับแล้ว ไม่ต้องเปลี่ยนไลบรารีส่งอีเมล

1. สร้างบัญชีที่ https://resend.com แล้วเพิ่มโดเมนผู้ส่งที่คุณหรือทีมเป็นเจ้าของ
2. เพิ่ม DNS ตามหน้าจอ Domains และรอให้ยืนยันสำเร็จ หากไม่มีสิทธิ์ DNS ของมหาวิทยาลัย ต้องให้เจ้าหน้าที่จัดการ หรือใช้โดเมนของโครงการที่เป็นเจ้าของ ห้ามตั้งผู้ส่งเป็นอีเมลมหาวิทยาลัยที่ยังไม่ได้ยืนยัน
3. สร้าง API key ที่ให้สิทธิ์ส่งอีเมล ตั้งเป็น `SMTP_PASSWORD` บนเซิร์ฟเวอร์ ห้ามส่งคีย์ในแชทหรือ commit
4. ใช้ค่าจาก `.env.resend.example` และตั้ง `MAIL_FROM` เป็นอีเมลในโดเมนที่ยืนยันแล้ว เช่น `Room Booking <booking@your-verified-domain>`
5. รีสตาร์ต backend และ worker (`npm run worker`) หรือกำหนด scheduler ของ deployment ให้เรียก endpoint งานอัตโนมัติ ตั้ง `CRON_SECRET` แบบสุ่มอย่างน้อย 32 ตัวอักษรสำหรับ scheduler
6. เปิดการแจ้งเตือน > ส่งอีเมลแจ้งเตือน เลือกบัญชีที่ลงทะเบียนและรายการจอง ส่ง แล้วตรวจสถานะและกล่องจดหมายจริง

หน้าเว็บแสดง “บริการอีเมลรับแล้ว” เมื่อ SMTP ยอมรับข้อความ ซึ่งยังไม่ยืนยันว่าถึง inbox ต้องตรวจกล่องจดหมายและ spam ด้วย ระบบลองส่งใหม่เมื่อผิดพลาดสูงสุด 5 ครั้ง และปฏิเสธผู้รับนอกโดเมนที่อนุญาต

คำขอจอง อนุมัติ ปฏิเสธ ยกเลิก ปิดห้อง ไม่เช็คอิน และบทลงโทษใช้ outbox เดียวกัน จึงต้องมี worker ทำงานต่อเนื่องหรือ scheduler ที่รันถี่พอสำหรับกฎเช็คอิน 30 นาที

เอกสารทางการ: https://resend.com/docs/send-with-smtp และ https://resend.com/docs/dashboard/domains/introduction

สถานะรอบนี้: เตรียมโค้ดและไฟล์ตัวอย่างแล้ว ยังไม่มี API key/โดเมนที่ยืนยัน จึงยังไม่ได้ส่งอีเมลจริงหรือแก้ค่าลับของระบบ
