# องค์ประกอบอัตลักษณ์มหาวิทยาลัยขอนแก่น

ใช้ไฟล์ต้นฉบับจากหน้าที่ผู้ใช้ระบุ: [ดาวน์โหลดตราและฟอนต์ มข.](https://building.kku.ac.th/downloads/kku-logo/)

- `apps/web/public/brand/kku-emblem-th.png`: ไฟล์ `th/LogoKKU thai.png` จากชุดตราภาษาไทย ไม่วาดทับ เปลี่ยนสี ตัดองค์ประกอบ หรือบิดสัดส่วน
- `apps/web/public/fonts/MorKhor1.ttf`: ฟอนต์ มข.๑ ที่มหาวิทยาลัยเผยแพร่ ใช้กับหัวข้อหลัก ภาษาไทยในฟอร์มและเนื้อหายังคง IBM Plex Sans Thai เพื่ออ่านง่าย
- สีหลัก `#A73B24` ตรงกับ RGB 167, 59, 36 ที่ระบุใน [ประกาศตราและสัญลักษณ์](https://building.kku.ac.th/47/)

ตราใช้ในหน้าเข้าสู่ระบบ เมนูหลัก และไอคอนเว็บ จัดวางบนพื้นที่เรียบ ไม่ใช้เป็นลายน้ำตกแต่ง แสดงตามสัดส่วนของไฟล์ต้นฉบับ

ลิขสิทธิ์ตราและฟอนต์เป็นของมหาวิทยาลัยขอนแก่น ให้เจ้าของโครงการตรวจขอบเขตการใช้ก่อนเผยแพร่เป็นบริการทางการ การนำเข้าชุดไฟล์ตามคำขอไม่ได้ยืนยันว่าระบบนี้ได้รับการรับรองจากมหาวิทยาลัย
