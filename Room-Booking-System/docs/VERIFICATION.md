# บันทึกการตรวจเว็บต้นแบบ

ตรวจเมื่อ 8 ตุลาคม 2569 ใช้ข้อมูลจำลองและเวลาเดโม ไม่เชื่อมฐานข้อมูลต้นฉบับ

## ผลตรวจ

- `npm.cmd test` ผ่าน 8/8 ชุด: จอง–อนุมัติ–ยกเลิก/คืนอุปกรณ์, เวลาทับซ้อนและเวลาต่อเนื่อง, rollback เมื่ออุปกรณ์ไม่พอ, สิทธิ์เจ้าหน้าที่/เจ้าของ, โควตาและช่วงจอง, check-in/no-show/ปิดรอบไม่ทำงานซ้ำ, การปิดห้อง, และตักเตือน/ระงับสิทธิ์
- `npm.cmd run build` ผ่านการตรวจ TypeScript และสร้างเว็บสำเร็จ
- ทดสอบในเบราว์เซอร์: ส่งคำขอพร้อมอุปกรณ์ → เปลี่ยนเป็นเจ้าหน้าที่ → อนุมัติ → กลับบัญชีผู้จอง → ยกเลิก ตรวจสถานะในตารางทุกขั้น
- เจ้าหน้าที่เห็นเฉพาะห้องที่ได้รับมอบหมาย รวมถึงจำนวนคำขอในเมนู
- เช็คอินรายการที่ถึงเวลา แล้วเลื่อนเวลาเดโมเพื่อจบรอบ
- ปิดห้องที่มีคำขอ ตรวจจำนวนรายการได้รับผลกระทบ และยืนยันคำขอถูกยกเลิกในหน้าพิจารณา
- พิจารณาระงับสิทธิ์ผู้ใช้ตัวอย่างที่มี no-show 3 ครั้ง ตรวจผลในบัญชีเจ้าตัว
- เพิ่มอาคาร แก้ไขจำนวนอุปกรณ์ บันทึกข้อมูลส่วนตัว และส่งคำถาม FAQ สำเร็จ
- ดาวน์โหลด CSV สำเร็จและตรวจหัวตาราง/ข้อมูลภาษาไทยจริง
- นำการแจ้งเตือนที่ล้มเหลวกลับเข้าคิว สำเร็จ
- ตรวจเว็บที่สร้างแล้วบนพอร์ต 5174: ส่งคำขอ รีเฟรช และยืนยันคำขอยังคงอยู่
- ตรวจหน้าแรกที่ความกว้าง 1440, 390 และ 320 พิกเซล จอเล็กไม่มีหน้าเว็บล้นแนวนอน แบบฟอร์มจองที่ 320 พิกเซลมีความกว้างเนื้อหาเท่ากับหน้าต่างฟอร์ม
- เมนูมือถือย้ายโฟกัสเข้าปุ่มปิด ปิดด้วย Escape แล้วคืนโฟกัสที่ปุ่มเปิดเมนู เนื้อหาพื้นหลังไม่รับโฟกัสระหว่างเมนูเปิด
- ไม่พบ console error/warning ใหม่ในรอบตรวจพรีวิวสุดท้าย
- คืนข้อมูลเริ่มต้นบนพรีวิวที่ส่งมอบ และคืนขนาดหน้าต่างเบราว์เซอร์ปกติ

## หมายเหตุการตรวจ

ระหว่างจัดรูปแบบหลายไฟล์และติดตั้งเครื่องมือจัดรูปแบบ หน้า dev เกิดข้อผิดพลาดชั่วคราวจาก hot reload/การปรับ cache ของ dependencies โหลดใหม่แล้วใช้งานได้ตามปกติ จึงตรวจซ้ำด้วยเว็บที่สร้างเสร็จ

พอร์ต 4173 ในเบราว์เซอร์มีแคชหน้าโปรเจคอื่น แม้ HTTP จากเซิร์ฟเวอร์ส่ง KKU Space ถูกต้อง จึงย้ายพรีวิวเป็น 5174 และยืนยันว่าการรีเฟรชปกติยังแสดงเว็บถูกต้อง

การตรวจนี้ยืนยัน workflow ในต้นแบบเดียว ไม่ใช่การทดสอบ Oracle, OAuth, การส่งอีเมล หรือผู้ใช้หลายคนพร้อมกัน ขอบเขตและข้อเสนอที่ยังไม่เปิดใช้ระบุใน README
