# CP SPACE

ระบบจองห้องสำหรับวิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น

- ใช้โลโก้จาก [เว็บไซต์ทางการ](https://computing.kku.ac.th/index) ต้นฉบับ https://computing.kku.ac.th/_nuxt/img/logo2.06d1225.png สีหลัก `#0776BC` มาจากโลโก้ คู่กับน้ำเงินเข้ม `#103B64` และฟ้าอ่อน `#E8F4FC`
- หน้าค้นหาห้องและคำแนะนำจากผู้ช่วยใช้ขอบเขตเดียวกันผ่าน `computingCatalog` โดยดูจากชื่ออาคารหรือหน่วยงานเจ้าของพื้นที่: วิทยาลัยการคอมพิวเตอร์, คณะวิทยาการคอมพิวเตอร์, อาคารวิทยวิภาส, College of Computing หรือ CP ที่เป็นคำแยก
- อาคารหรือห้องที่เลิกใช้งานไม่ปรากฏในการค้นหา รหัสห้องที่ขึ้นต้นด้วย CP เพียงอย่างเดียวไม่ทำให้อาคารของคณะอื่นอยู่ในขอบเขต
- ไม่ลบหรือย้ายข้อมูลอาคาร ห้อง ผู้ใช้ หรือประวัติการจองในฐานจริง ผู้ดูแลยังเปิดข้อมูลเดิมได้ หากฐานจริงยังไม่มีอาคาร CP หน้าค้นหาจะแสดงสถานะไม่พบห้อง จนกว่าผู้ดูแลจะเพิ่มข้อมูลพื้นที่ CP ที่ยืนยันแล้ว
- ข้อมูลจำลองเป็นห้อง CP 6 ห้องในอาคารที่ระบุชัดว่าเป็นข้อมูลจำลอง ไม่ใช่รายชื่อหรือความจุห้องจริง
- การเข้าสู่ระบบยังใช้บัญชี Google ของมหาวิทยาลัย และสิทธิ์เดิม การปรับขอบเขตการค้นหาไม่ใช่การยืนยันสังกัดของผู้ใช้ และไม่เปลี่ยนการเข้าถึงประวัติเดิม
- เก็บชื่อฐานข้อมูล workspace packages และ storage/session keys เดิม เพื่อรักษาความเข้ากันได้และข้อมูลที่บันทึกไว้

ตรวจด้วย production build, ชุดทดสอบหลัก และเบราว์เซอร์ที่ความกว้าง 1440, 390 และ 320 พิกเซล
